# DHCP and Routing

A collection of Cisco Packet Tracer exercises covering DHCPv4 configuration and IPv4 routing using static, floating static, default, and RIPv2 routes.

## Exercises

### DHCPv4 Using Cisco IOS

Configured DHCPv4 services using Cisco IOS and verified address assignment to network clients.

**Directory:**

```text
Configuring_DHCPv4_Using_Cisco_IOS/
```

### DHCPv4 Using a DHCP Server

Configured a dedicated DHCP server in Cisco Packet Tracer to provide IPv4 addressing to network clients.

**Directory:**

```text
Configuring_DHCPv4_Using_DHCP_Server/
```

### Floating Static Routes

Configured floating static routes to provide an alternative routing path with a higher administrative distance.

**Directory:**

```text
Configuring_Floating_Static_Routes/
```

### IPv4 Static and Default Routes

Configured IPv4 static routes and default routes to establish connectivity between networks.

**Directory:**

```text
Configuring_IPv4_Static_and_Default_Routes/
```

### RIPv2

Configured **Routing Information Protocol version 2 (RIPv2)** for dynamic IPv4 routing.

**Directory:**

```text
Configuring_RIPv2/
```
