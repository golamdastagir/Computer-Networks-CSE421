# Computer Networks(CSE421) Labs

A collection of hands-on computer networking labs completed as part of coursework covering network architectures, protocols, network programming, routing, addressing, and network applications.

The labs use **Cisco Packet Tracer, Wireshark, NS-3, and Python socket programming** to explore practical networking concepts including TCP/IP, DNS, ARP, HTTP, SMTP, TCP, UDP, NAT, DHCP, static routing, dynamic routing, and network troubleshooting.
