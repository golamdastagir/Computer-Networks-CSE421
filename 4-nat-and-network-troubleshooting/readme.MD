# NAT and Network Troubleshooting

A collection of Cisco Packet Tracer exercises focused on Network Address Translation, connectivity testing, and systematic network troubleshooting.

## Exercises

### Static and Dynamic NAT

Implemented and tested:

* Static NAT
* Dynamic NAT
* Inside and outside network address translation
* NAT configuration and verification

**Directory:**

```text
Implementing_Static_and Dynamic_NAT_Instructions/
```

### Ping & Traceroute

Used Cisco Packet Tracer to test network connectivity using:

* `ping`
* `traceroute`

The exercise focuses on identifying connectivity between network devices and using diagnostic tools to trace network paths.

**Directory:**

```text
Ping_and_Traceroute_to_Test_Network_Connectivity/
```

### Troubleshooting Connectivity Issues

Worked through a simulated network with connectivity problems and used Cisco IOS commands and systematic troubleshooting techniques to identify configuration issues.

**Directory:**

```text
Troubleshoot_Connectivity_Issues/
```

## Networking Concepts

* Network Address Translation (NAT)
* Static NAT
* Dynamic NAT
* Network connectivity testing
* Ping
* Traceroute
* Cisco IOS troubleshooting
* Network configuration verification

## Tools

* Cisco Packet Tracer
* Cisco IOS CLI
